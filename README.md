# Adrian Tam — AI Deployed Engineer

Personal portfolio for Adrian Tam, focused on production AI delivery, deployed
impact, and selected engineering work.

The site is built with Vue 3, TypeScript, and Vite. Three.js powers the
interactive hero visualization.

## Development

```bash
npm ci
npm run dev
```

Vite prints the local development URL in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The build command runs Vue TypeScript checks before generating the production
bundle in `dist/`.
